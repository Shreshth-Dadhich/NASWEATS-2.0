# EarthSignal 7 architecture and scientific contract

React connects eleven precisely labeled public measurements through dataLoader: memory/IndexedDB, compressed NASA snapshots, POWER's API, the same-origin NCCS relay, indexed GSFC GRACE mascons and 340 monitored GSFC GWM lake point records. See README for fields, periods, units and scientific limitations.

The hosted Worker serves dist/client through ASSETS and relays only allowlisted public NASA NCCS subsets. It validates native DAS units, bounded indices and source dimensions, and preserves the original response. It is not a general-purpose proxy. Optional native mission acquisition remains a separate Python FastAPI service with explicit product configuration, supported decoders, QA and backend-only authentication.

Study extents are limited to 12 degrees per axis within ±180 longitude / ±85 latitude. Dateline crossings must be split. Global locations are supported; whole-planet statistical acquisition is not. Native measurement resolution is never enhanced to match the attributed Esri basemap. NASA GIBS relief remains an alternate basemap.

POWER uses half-cell padding and bounded five-degree tiles. GMI uses eight five-year requests, two concurrent. Twelve presets are warmed from real NASA responses. GRACE downloads intersecting indexed native tiles: OBP land flag 80 or SLA ocean flag 90. Mission gaps remain null. Lake monthly means and counts come from real overpasses at monitored points. Lake heights, land storage and sea-level mass are separate quantities.

The analysis worker retains grids and polygon weights, coalesces slider input and discards obsolete calculations. Map cells, chart, statistics and research export share the same completed result. Exports are disabled while recalculating. Leaflet retains a canvas layer and updates its styles. Plotly loads separately from the initial application bundle. Memory/IndexedDB caches and the hosted relay reuse previously acquired source data. Cold NASA latency remains variable.

Monthly regional means use polygon intersection weights and require 80% valid coverage of the selected source domain. Masked GRACE exports include selected-domain fraction. Complete annual/seasonal samples are required; December in DJF belongs to the following January year. Monthly anomalies use a fixed full-record climatology. Inference requires five complete samples. OLS uses elapsed calendar years, Student t tests the slope, and fitted-mean bands differ from prediction intervals. MK uses an exact conditional permutation distribution through 100 annual samples, including ties; longer records use a labeled approximation. No serial-correlation or multiple-testing correction is applied. Regression intervals do not propagate source uncertainty. Significance does not identify a cause.

Source manifests preserve URLs, processing, metadata and SHA-256 references. Large HDF5 originals are referenced by URL/hash rather than copied into each researcher download. No data source is silently substituted on error. OSCAR currents and full Jason/SWOT sea-surface height remain unconnected exact products. Surface skin temperature covers land and sea; ocean mass excludes thermal expansion. An Earthdata account alone does not configure native product decoding or the Python service.

The V1 dashboard now remains mounted when the supplied study opens in a focus-trapped dialog. Closing it preserves the investigation. The global relationship worker pairs independently reduced NASA records by exact monthly dates or complete annual/seasonal years and calculates descriptive Pearson r. The source mask for topsoil follows native gwetroot validity. Four new public metric variants use the bounded NCCS relay; failed-QA global dust mass fields are excluded. See GLOBAL_SOURCE_AUDIT.md for the source audit and README for the current 15-metric/12-button catalogue.

## Full-page supplied study

App keeps the live Dashboard mounted in a hidden wrapper while the supplied ResearchStudy occupies the full document; it is no longer placed inside Dialog. The #study view selects a dedicated workspace tab. StudyWorkbench contains pure projections from the verified supplied dataset: six-scope annual traces, raw and detrended-anomaly pairs, descriptive fits and lookup of supplied tests. StudyEvidence renders directional regional tables, native accessible bar charts, nine-variable region profiles and scope/relationship matrices. StudySources preserves the prior provenance, source-file and original-PNG views.

Published inference and newly computed descriptions are explicitly separate. Thirty-four original relationship tests retain their supplied p/q, effective-N and ACF values. Unreported tests never receive fabricated q-values or a significant/not-significant label. Study exports include original hash-checked source files, a normalized all-scope annual table, and original plus residual monthly pair coordinates.

Map camera minimum zoom is based on fitting the regional extent with one additional zoom-out level. Whole peninsula is a camera action rather than a change to the numerical selection. Acquisition still validates the Middle East extent and 12-degree selection limit. Polygon controls retain visible vertices and editable drafts; the existing spherical cell/polygon overlap weighting supplies the actual area averages and source-cell clipping.


## Study atlas projections

`studyMapModel.js` projects the verified tables into five-region frames and export rows. It handles annual/monthly observations, mean annual values, source OLS changes, source Sen/FDR classes and correlation evidence, preserving null separately from zero. `StudyMapExplorer` owns playback and control state, assembles the selected-region analysis and emits a current-frame research CSV. `StudyMap` uses stable Leaflet paths with permanent numeric tooltips and mouse/keyboard region selection. Region geometries remain the specification's analytical rectangles. Playback changes source-table indices only; statistical tests stay fixed to the supplied period and families.
